# Checker

Use to show transparency in an image or material preview. It is a utility surface; use the other backgrounds for ordinary page content.

```css
.bg-checker {
  background: repeating-conic-gradient(#222 0 25%, #151515 0 50%)
    0 0 / 20px 20px;
}
```

The 20px tile creates 10px squares. Keep both shades close so the preview remains the focus.

Source: [styles.css](../../src/styles.css), `.bg-checker`.
