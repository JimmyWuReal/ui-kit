# Card surface

Use `#111111` to group content on the page. This is the gallery's card surface, distinct from the standalone [card element](../elements/card.md), which uses `#161616`.

```css
.bg-card { background: #111; }
```

A gallery-style container uses a 20px radius. Choose padding for the content; keep the surface flat without a decorative shadow or outline. Add a container when it helps group content, rather than wrapping every section or nesting panels by default.

Source: [styles.css](../../src/styles.css), `.bg-card`, `.grid-cell`, `.sample-card`.
