# Card surface

Use `#111111` to group content on the page. This is the gallery's card surface, distinct from the standalone [card element](../elements/card.md), which uses `#161616`.

```css
.bg-card { background: #111; }
```

A gallery-style container uses a 20px radius. Choose padding for the content; a surface does not require a shadow or outline.

Source: [styles.css](../../src/styles.css), `.bg-card`, `.grid-cell`, `.sample-card`.
